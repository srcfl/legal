# Integritetspolicy

_Gäller från: 2025-10-30_

## Inledning

Välkommen till Sourceful Labs AB, organisationsnummer 559382-0458 ("vi", "vår" och "oss"), leverantör av webbplatsen **www.sourceful.energy**, app och relaterade tjänster. Vi tar våra användares integritet och säkerhet på allvar. Denna integritetspolicy innehåller information om när och hur vi behandlar dina personuppgifter och vilka rättigheter du har i samband med denna behandling.

## Personuppgiftsansvarig

Sourceful är personuppgiftsansvarig för behandlingen av dina personuppgifter och ansvarar för att all behandling sker i enlighet med tillämplig lagstiftning.

### Analys- och marknadsföringstekniker

Vi använder olika analys- och marknadsföringsverktyg för att förstå hur besökare interagerar med vår webbplats, förbättra våra tjänster och leverera relevant reklam. Dessa verktyg samlar in och behandlar uppgifter enligt beskrivningen nedan.

**Meta (Facebook) Pixel**
Vi använder Meta Pixel för att mäta effektiviteten i våra annonskampanjer och förstå hur besökare interagerar med vår webbplats efter att de har sett våra annonser på Facebook och Instagram. Meta Pixel samlar in information om ditt besök, inklusive besökta sidor, vidtagna åtgärder och enhetsinformation. Dessa uppgifter hjälper oss att optimera vår annonsering och visa dig relevant innehåll om våra energilösningar.
Meta behandlar dessa uppgifter i enlighet med sin integritetspolicy. Du kan styra hur Meta använder dina uppgifter för annonseringssyften via dina Facebook Ad Preferences.

**TikTok Pixel**
Vi använder TikTok Pixel för att mäta och optimera våra annonskampanjer på TikTok. Pixeln samlar in uppgifter om din webbplatsaktivitet, vilket hjälper oss att förstå kampanjresultat och nå relevanta målgrupper. TikTok kan kombinera dessa uppgifter med information från ditt TikTok-konto för att personalisera annonseringen.
Du kan hantera dina TikTok-annonseringsinställningar via inställningarna för ditt TikTok-konto.

**LinkedIn Insight Tag**
Vi använder LinkedIn Insight Tag för att spåra konverteringar från våra annonskampanjer på LinkedIn, få insikter om våra webbplatsbesökare och bygga målgrupper för framtida kampanjer. Taggen samlar in uppgifter om ditt besök, inklusive besökta sidor och vidtagna åtgärder.
LinkedIn-medlemmar kan styra hur deras uppgifter används för annonsering i sina LinkedIn-kontoinställningar. Icke-medlemmar kan välja bort detta via LinkedIns kontroller för gäster.

**Reddit Pixel**
Vi använder Reddit Pixel för att mäta effektiviteten i vår annonsering på Reddit och förstå hur Reddit-användare interagerar med vår webbplats. Pixeln samlar in information om din surfaktivitet, inklusive besökta sidor, vidtagna åtgärder och konverteringshändelser. Detta hjälper oss att optimera våra annonskampanjer på Reddit och nå relevanta communities som är intresserade av energiteknik.
Reddit kan matcha dessa uppgifter med ditt Reddit-konto för att tillhandahålla personaliserad annonsering. Du kan styra dina Reddit-annonseringsinställningar via inställningarna för ditt Reddit-konto eller välja bort personaliserad annonsering på www.reddit.com/personalization.

**HubSpot**
Vi använder HubSpot som vår plattform för kundrelationshantering (CRM) och marknadsföringsautomation. HubSpot hjälper oss att hantera kommunikation, följa kundinteraktioner och analysera webbplatsbeteende. Uppgifter som samlas in inkluderar kontaktuppgifter som du lämnar, sidor du besöker, e-postmeddelanden du öppnar och formulär du fyller i.
HubSpot behandlar dessa uppgifter på vårt uppdrag och lagrar dem säkert inom Europeiska ekonomiska samarbetsområdet där det är möjligt.

**Microsoft Clarity**
Vi använder Microsoft Clarity för att förstå hur besökare använder vår webbplats genom sessionsinspelningar och värmekartor. Clarity samlar in information om hur du interagerar med vår webbplats, inklusive musrörelser, klick och scrollningsbeteende. Detta hjälper oss att identifiera användbarhetsproblem och förbättra användarupplevelsen.
Microsoft Clarity samlar inte in personligt identifierbar information i sessionsinspelningar. Uppgifterna behandlas i enlighet med Microsofts integritetspolicy.
